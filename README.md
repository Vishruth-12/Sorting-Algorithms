# Sorting-Algorithms

A collection of small CPP practice programs organized into topic folders.

## Folder structure

- `sorting/bubble_sort.cpp`
- `sorting/selection_sort.cpp`
- `sorting/insertion_sort.cpp`
- `sorting/merge_sort.cpp`

## Run examples

Use a suitable CPP compiler/interpreter for the source file you want to run. For C++ examples, compile with C++17, for example:

```bash
g++ -std=c++17 path/to/program.cpp -o program
./program
```

For C programs use `gcc path/to/program.c -o program`; for Java compile with `javac FileName.java` and run with `java ClassName`; for Python run `python path/to/program.py`.
