# Sorting-Algorithms

A collection of C++ sorting practice programs organized in the `sorting/` folder.

## Programs
- `sorting/bubble_sort.cpp`
- `sorting/selection_sort.cpp`
- `sorting/insertion_sort.cpp`

Compile using a C++17 compiler, e.g. `g++ -std=c++17 sorting/bubble_sort.cpp -o app`. Prepared on 2026-10-12.
